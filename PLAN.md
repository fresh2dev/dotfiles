an ordered plan. File references are repo-relative; line numbers are from the current
`dev` branch.

## A. Outright bugs (things that fail or do the wrong thing)

1. **`home/.zshrc:125` — malformed `if` condition.**
   `if ! command -v ghostty &>/dev/null [ -e "/Applications/Ghostty.app" ]; then`
   passes `[`, `-e`, the path and `]` as extra arguments to `command -v`. The `-e` test
   never runs. Intended: `if ! command -v ghostty &>/dev/null && [ -e "/Applications/Ghostty.app" ]; then`.

2. **`home/.gitconfig` — `cva` and `ce` aliases call `git command`, which does not exist.**
   `cva = command --verbose --amend` and `ce = command --amend --no-edit` should be
   `commit --verbose --amend` and `commit --amend --no-edit`.

3. **`home/.gitconfig` — `wta` alias has a typo that deletes the wrong worktree.**
   Sets `TARGET_WT` then calls `git wt -d "$TRAGET_WT"` (empty variable). The delete step
   never receives a branch name.

## C. Inconsistencies between files

1. **`GOBIN` is set to two different values.** `home/.profile:12` sets
   `GOBIN=$GOPATH/bin` and puts it on `PATH`; `home/.config/mise/config.toml`
   `[env]` sets `GOBIN=$UV_TOOL_BIN_DIR` (`~/.local/bin`). Which one wins depends on
   whether `mise activate` has run yet. Pick one (recommend `~/.local/bin`, matching
   `UV_TOOL_BIN_DIR`) and remove the other.

2. **`kc` alias defined twice**: `home/.zshrc:113` and mise `[shell_alias]`. Keep the
   mise one.

3. **`EDITORCONFIG="$XDG_CONFIG_HOME/editorconfig"`** in mise `[env]` points at a file
   that does not exist; the repo ships `home/.editorconfig`. Move the file or fix the
   variable (note: `EDITORCONFIG` is not a variable editorconfig-core honors; confirm
   which tool reads it before keeping it at all).

4. **Two Brewfiles.** Root `.Brewfile` (marked `# TODO: deleteme`) and
   `home/.config/brewfile/Brewfile` (the real one, referenced by
   `HOMEBREW_BUNDLE_FILE_GLOBAL`). They already diverge (`cask "zed"` vs `cask zed`).
   Delete the root one.

5. **Tool installation is split across three mechanisms with overlap.**
   `apps.just` (`cargo binstall`, `go install`, `uv tool install`, brew) and mise
   `[tools]` both install: ripgrep, fd, bat, delta, zoxide, starship, viddy, zellij
   (both pin 0.45.1), lazygit, fzf, gum, k9s, yq, prek, ruff, git-cliff,
   git-filter-repo, copier, shfmt, stylua, tree-sitter-cli, git-graph, mcfly, bottom,
   lsd, tombi. `apps.just` already carries `# TODO: integrate mise`. Decide on mise as
   the source of truth and prune `apps.just` down to what mise cannot install
   (brew casks, zsh plugins, zellij wasm plugins).

6. **`home/.config/just/dotfiles.just` is orphaned.** The global
   `home/.config/just/justfile` mounts `mod? dotfiles x"$DOTFILES_DIR/justfile"`,
   i.e. this repo's root justfile, not `dotfiles.just`. Nothing references
   `dotfiles.just`; `py.just` is empty; `docs.just` and `common.just` are not mounted
   either. Either mount them (`mod? docs`, `mod? common`) or delete them.

7. **`DOTFILES_DIR` is required but never set.** `dotfiles.just` and the global
   justfile both read it; no rc file or mise `[env]` exports it. Add it to mise `[env]`
   (or `.profile`) so `just dotfiles link` works from a fresh shell.

8. **`home/.gitconfig` credential helper is `!~/.local/bin/gh auth git-credential`**,
   but `gh` is installed by mise (`github-cli = "2.100.0"`) into mise's shims dir, not
   `~/.local/bin`. Use bare `!gh auth git-credential` and let `PATH` resolve it.

9. **`home/.vim/vimrc.d/plugins.vimrc` is never sourced.** `home/.vimrc` has no
   `source`/`runtime` line for `vimrc.d/`. Confirm whether it is intentionally dead
   (neovim config lives in a separate `nvim-config` repo per Zed's ssh project list).

10. **`.zshrc` hard-requires tools that are optional elsewhere.** `fzf --zsh`,
    `starship`, `zoxide`, `direnv`, `mcfly`, and `kubectl completion zsh` are all
    eval'd unconditionally, while atuin, fzf-tab, autosuggestions and syntax
    highlighting are guarded. A shell without `kubectl` prints an error at every start.
    Guard each with `command -v`.

11. **`install-zellij-plugins` is macOS-only.** It `rm -rf`s
    `~/Library/Caches/org.Zellij-Contributors.Zellij` and nothing else. Harmless on
    Linux but misleading; the actual download is in `update-zellij-plugins`.

12. **`install-brew` starts `colima` and `syncthing` services**, which only makes sense
    on macOS. Fine, but should be guarded with `|| true` per-service (it is) and noted.

## D. Repo hygiene

1. **`home/.bash_history` is tracked** (contents: `exit`). Stow would symlink the
   live bash history into the repo, so every bash session would dirty the working tree.
   Remove from git and add to `.gitignore`.
2. **`.gitignore` is empty.** At minimum: `home/.bash_history`, `*.bak`, `.DS_Store`.
3. **`home/README.md` is stale.** Says "Apply with `DOOT_DIR=... doot`" and a
   placeholder list ("one", "two"). The real apply mechanism is `just link`. Rewrite or
   delete (it is stow-ignored anyway, so it only exists for GitHub readers).
4. **Root `README.md` is empty.** Add a short "clone, set `DOTFILES_DIR`, `just link`"
   section.
5. **`.gitattributes` configures git-crypt for `private-*/`** but no such directory
   exists and git-crypt is not listed in any install recipe. Either add `git-crypt` to
   mise/brew or drop the filter lines until needed.
6. **`home/.config/zellij/config.kdl` is an autogenerated dump** (header says so).
   Consider trimming to the non-default overrides so future diffs are readable.
7. **`home/.config/mise/config.toml` `sshs = "purple"  # TODO: install purple`** — `purple-ssh`
   is installed by `install-cargo`, so the TODO is done; remove the comment or move
   `purple-ssh` to mise `[tools]` with the rest.

## E. Platform-specific files stowed everywhere

Not bugs, but worth a decision: `home/Library/LaunchAgents/setenv.XDG_CONFIG_HOME.plist`,
`home/.colima/`, `home/.homebrew/trust.json`, and
`home/.config/mise/config.macos-arm64.toml` are macOS-only and get symlinked onto Linux
hosts too. Stow supports multiple packages; splitting into `home/` (common) and
`home-macos/` with a `just link` that picks packages by `uname` would keep Linux `$HOME`
clean. The mise `[bootstrap.macos.launchd.agents.my-sync]` block already duplicates the
plist's job, so the plist may be removable outright.

## Implementation notes (2026-09-06)

All four phases were implemented on `dev`. Decisions taken where the plan left options:

- **A8 / `.bashrc`**: added a minimal `home/.bashrc` (interactive guard + `mise activate bash`).
- **B / zellij**: `file:` relative paths resolve against cwd and the *data* dir
  (`~/.local/share/zellij/plugins`), not the config dir (verified on 0.45.1). `~` does
  expand, so plugins are referenced as `file:~/.config/zellij/plugins/<name>.wasm`. The
  `zellij-automode` repo is not public and has no release, so the alias, its
  `load_plugins` entry and the `MessagePlugin "automode"` keybinds were removed.
- **B / zed**: `timpi`/`timxl` hosts not verified from this box; only the trailing `./` was fixed.
- **C1 `GOBIN`**: `~/.local/bin` everywhere (`.profile` now sets `GOBIN="$MY_TOOL_DIR"`).
- **C3 `EDITORCONFIG`**: variable removed; `home/.editorconfig` stays and is picked up
  by normal upward lookup from anything under `$HOME`.
- **C6 just modules**: `dotfiles.just` deleted; `common`, `docs`, `py` mounted from the
  global justfile.
- **C7 `DOTFILES_DIR`**: `${DOTFILES_DIR:-$GHQ_ROOT/github.com/fresh2dev/dotfiles}` in
  mise `[env]`, so a pre-exported value wins.
- **C9**: `.vim/vimrc.d/plugins.vimrc` was unreferenced; deleted.
- **D5 git-crypt**: `.gitattributes` removed. Re-add when a `private-*/` dir exists.
- **D3**: `home/README.md` deleted; root `README.md` written.
- **Phase 3**: everything from `install-{cargo,go,uv,npm,dotnet}` moved to mise `[tools]`
  with pinned versions resolved via `mise latest` on 2026-09-06. Dropped as redundant
  under mise: `cargo-cache`, `cargo-update`, `gup`, `rust-just` (mise `just`),
  `bun`-installed npm packages (now `npm:`), `dotnet tool` PowerShell (now aqua
  `powershell`). `rustup component add rust-analyzer` became the registry `rust-analyzer`.
  `atuin` was already commented out in `apps.just` and stays uninstalled; `.zshrc` still
  supports it if present.
- **Phase 4**: `home-macos/` holds `.colima/`, `.homebrew/`, the Brewfile and
  `mise/config.macos-arm64.toml`. The LaunchAgent plist was deleted because the mise
  `[bootstrap.macos.launchd.agents.my-sync]` block does the same `launchctl setenv`.
- **Not done**: `just relink` on this box. The dotfiles are not stowed here (`stow` is not
  installed and `~/.zshrc` is a real file), so verification was syntax/parse checks only.
